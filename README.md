Questions
#What is Version Control?
Version Control is a system that tracks and manages changes in files and projects over time . It helps us to see old versions and work safely with others.
#What is Git?
Git is a free and open-source version version control system.
#What is GitHub?
GitHub is a web-based platform that stores Git repositories in the cloud, allowing developers to work together on projects. 
#What is Git Bash?
Git Bash is a Microsoft Windows application that provides a Linux/Unix-style command-line experience for running Git and terminal commands.
#What are the main parts of GitHub?
The main parts of GitHub are its core version control elements and collaboration tools that help people build software together.
#What are the stages of Git/GitHub?
The 4 Main Git and GitHub Stages_ 1. The Working Directory,2. The Staging Area / Index,3. The Local Repository ,4. The Remote Repository .
